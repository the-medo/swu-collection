# Currency icons

Original, small SVG illustrations for SWUBASE: a gold credit chip with stamped
markings and a smooth silver beskar ingot. The shared `CurrencyIcon`
component displays them beside the currency labels and amounts.

Visual references:

- [Imperial credits — Star Wars Databank](https://www.starwars.com/databank/imperial-credits)
- [Beskar — Star Wars Databank](https://www.starwars.com/databank/beskar)

The SVGs are drawn for the interface; no reference photography is bundled.
